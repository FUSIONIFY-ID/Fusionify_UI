Tagihan

Membuat tagihan.

Buat tagihan dari server kamu, lalu arahkan pembeli ke url_bayar. Begitu pembayaran masuk, kami mengirim webhook ke server kamu.

Sebelum mulai

  • Akun merchant yang sudah disetujui.
  • API key dari dashboard, menu Pengaturan → API key. Pakai kunci uji (sk_test_) selama mencoba.
  • Server yang bisa menerima permintaan HTTPS untuk webhook.

Autentikasi

Kirim kunci rahasia di header Authorization setiap permintaan.

Header
Authorization: Bearer sk_test_xxxxxxxxxxxxxxxx
Kunci rahasia hanya untuk server.

Jangan menaruhnya di kode browser, aplikasi HP, atau repositori publik. Kalau bocor, buat kunci baru di dashboard dan matikan yang lama.

Membuat tagihan

POST/v1/tagihan
FieldTipeKeterangan
nomor wajibstringNomor tagihan dari sistem kamu. Harus unik.
jumlah wajibintegerJumlah dalam Rupiah, tanpa titik atau desimal.
keteranganstringTampil di halaman bayar. Maksimal 120 karakter.
callback_urlstringAlamat webhook khusus tagihan ini. Kosongkan untuk memakai alamat di dashboard.
Terminal
curl https://api.nama-produk.id/v1/tagihan \
  -H "Authorization: Bearer $NP_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "nomor": "INV-2026-0142",
    "jumlah": 150000,
    "keterangan": "Paket bulanan, Oktober 2026",
    "callback_url": "https://tokobudi.id/webhook/bayar"
  }'
Node.js
// Jalankan di server, jangan di browser. Kunci rahasia tidak boleh sampai ke pengunjung.
const res = await fetch("https://api.nama-produk.id/v1/tagihan", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.NP_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    nomor: "INV-2026-0142",
    jumlah: 150000,
    keterangan: "Paket bulanan, Oktober 2026",
    callback_url: "https://tokobudi.id/webhook/bayar",
  }),
});
const tagihan = await res.json();
PHP
<?php
$ch = curl_init("https://api.nama-produk.id/v1/tagihan");
curl_setopt_array($ch, [
  CURLOPT_POST => true,
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_HTTPHEADER => [
    "Authorization: Bearer " . getenv("NP_SECRET_KEY"),
    "Content-Type: application/json",
  ],
  CURLOPT_POSTFIELDS => json_encode([
    "nomor" => "INV-2026-0142",
    "jumlah" => 150000,
  ]),
]);
$tagihan = json_decode(curl_exec($ch), true);

Respons

Kalau berhasil, API membalas 201 Created dengan data tagihan.

JSON
{
  "id": "tg_01JB7Q2M4X",
  "nomor": "INV-2026-0142",
  "jumlah": 150000,
  "status": "menunggu",
  "url_bayar": "https://bayar.nama-produk.id/tg_01JB7Q2M4X",
  "kedaluwarsa": "2026-10-26T07:35:00Z"
}

Status tagihan: menunggu, berhasil, kedaluwarsa, atau gagal.

Webhook

Saat status tagihan berubah, kami mengirim POST ke callback_url dengan header X-Signature. Cek tanda tangannya dulu sebelum mempercayai isinya.

Node.js
import crypto from "node:crypto";

// rawBody = isi permintaan apa adanya (Buffer/string), sebelum di-parse JSON
function tandaTanganValid(rawBody, tanda) {
  const hitung = crypto.createHmac("sha256", process.env.NP_WEBHOOK_SECRET).update(rawBody).digest("hex");
  return tanda?.length === hitung.length && crypto.timingSafeEqual(Buffer.from(hitung), Buffer.from(tanda));
}
Balas cepat.

Kirim 200 dalam 10 detik, lalu proses pesanan di belakang. Webhook yang gagal dikirim ulang beberapa kali, jadi pastikan pesanan yang sama tidak diproses dua kali.
